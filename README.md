### 🚀 Sobre Mim

Engenheiro de Software / Desenvolvedor **Full Stack & Mobile** com sólida experiência prática na concepção, arquitetura e entrega de aplicações ponta a ponta. Atuo desde o levantamento de requisitos de negócio, modelagem de bancos de dados relacionais robustos, construção de APIs RESTful de alta performance, até interfaces web intuitivas e aplicativos mobile nativos e híbridos para produção.

- 🏛️ **GovTech & Cidades Inteligentes:** Arquiteto e desenvolvedor do ecossistema **Cidadão Inteligente** (Web & App) para a gestão pública municipal de Itapecerica da Serra - SP.
- 🛒 **Marketplaces & FinTech:** Criação de plataformas completas de intermediação de serviços e comércio de maquinário pesado com checkout e pagamentos integrados (**Mercado Pago API**).
- ⚙️ **Engenharia de Software:** Domínio aprofundado em **PHP/Laravel, Node.js, TypeScript, React, React Native (Expo), TailwindCSS, Docker** e bancos de dados relacionais (**MySQL, PostgreSQL**).
- 🎯 **Foco em Resultados:** Código limpo, componentização modular, segurança e foco em soluções que resolvem problemas reais de usuários e empresas.
